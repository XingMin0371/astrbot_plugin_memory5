# 鱼鱼日记 · 如鱼所书（memory5）

把群聊和私聊整理成**分层日记**，在对话时按需注入，并提供一个可以查看、修改、删除记忆的面板。

> 插件内部名：`memory5`（目录、配置、数据路径始终不变）

## 为什么做这个

大多数“记忆”插件只是把聊天记录塞进上下文，越聊越乱。这个插件的思路是：

1. **先分层，再注入**：长期 / 重要 / 提醒 / 普通 / 低密度，各自有不同的保留期和注入预算；
2. **归档是整理，不是堆积**：按固定时间把原始消息整理成条目，跨标签去重，重要的才进长期；
3. **记忆要能被看见和修改**：面板里能按群/QQ、按日期翻，错了能改、能删、能恢复；
4. **隐私默认收紧**：日记落盘加密，密钥在本机，导出可选加密包。

## 核心设计

### 1. 分层记忆

| 层 | 内容 | 用途 |
|---|---|---|
| 长期 | 稳定的事实、关系、称呼 | 每轮优先注入 |
| 重要 | 有影响但不必长期的事实 | 按预算注入 |
| 提醒 | 带到期时间的事件 | 到点发送 + 临期注入 |
| 普通 / 低密度 | 日常闲聊 | 随机抽取，保留期短 |

分层由稳定度、影响力、信息量三个维度打分，阈值可在设置里调。

### 2. 归档流程

```
原始消息（按天 jsonl）
  → 按时间槽触发（默认 04:05 / 16:05）
  → 批量交给模型整理成条目
  → 跨标签去重
  → 重要条目升级进长期
  → 重排各文件序号、刷新索引
```

### 3. 注入

按预算拼装：长期 → 共享身份/称呼/关系 → 重要 → 随机普通；超预算时按优先级裁剪。提醒只在触发点前后窗口内注入，省 token。

### 4. 加密

三档可选：

- 高性能：AES-256-GCM
- 平衡：AES-256-GCM + HKDF-SHA256 子密钥（推荐）
- 安全：再加 HMAC-SHA256

密钥首次安装自动生成；支持轮换（半天/一天/一周/一月/一年）；密钥不可用时可三级确认重置（旧数据移到 `memory5-old-时间戳`，新钥无法解密）。

### 5. 面板

- 按范围（群/私聊）、日期（日历，可选“全部”）查看
- 长期 / 重要 / 提醒 / 普通 / 低密度 / 别名 / 回收站 / 定时任务
- 支持编辑、删除（进回收站 7 天）、恢复、彻底删除
- 批量删除、批量调整等级（按日期+序号精确定位）
- 导出（JSON/Markdown）与导出历史
- 运行状态面板：版本、会话、加密、缓存、条目数、备份校验

### 6. 提醒与定时任务

- 提醒：提前量、提醒次数、补发宽限、过期回落都可调
- 重复：每天 / 每周 / 工作日
- 定时任务：一次性 / 每天 / 每周，支持图片、语音、视频

## 功能一览

- 分层日记与自动归档
- 按需注入，预算可控
- 提醒到点发送、临期注入
- 定时任务与富媒体
- 面板查看 / 编辑 / 删除 / 恢复
- 别名管理（QQ、昵称、置信度）
- 导入导出、导出历史
- 三档加密、密钥轮换、备份校验
- 行业敏感词脱敏（内置词表 + 自定义）
- 多会话、多群、私聊

## 优点

- **不乱**：分层 + 去重，上下文不会被闲聊淹没
- **可控**：字符预算、保留期、注入条数都能调
- **可改**：记忆不是黑盒，面板里能逐条改
- **可恢复**：删除进回收站，误删能找回
- **隐私**：落盘加密，密钥不出本机
- **轻依赖**：不额外安装 Python 包，用 AstrBot 自带的 `cryptography`

## 安装

1. 把 `astrbot_plugin_memory5` 目录放到 AstrBot 数据目录的 `plugins/` 下
2. 重启 AstrBot
3. 首次启动自动生成密钥，打开插件面板即可

详细步骤见 [DEPLOY.md](DEPLOY.md)。

## 配置要点

- `记录的会话`：填 `group:群号` 或 `private:QQ号`，不填不归档
- `管理员 QQ`：可查看全部日记、使用重要级命令
- `机器人 QQ`：识别自身消息
- 注入预算：按需调，默认 3600 字符
- 加密强度：平衡即可；切换会自动重加密

## 命令

```
/记忆查看 [日期] [QQ] [普通级|提醒级|重要级|低密度级] [条数]
```

长期记忆只在面板查看。

## 数据目录

```
<数据目录>/memory5/
├─ group_xxx/ private_xxx/
│  ├─ core.md important.jsonl remind.jsonl
│  ├─ daily/*.jsonl raw/*.jsonl
│  ├─ aliases.json index.json
├─ tasks.json
├─ trash/ media/ backup_policy.json
└─ export_history.json
```

密钥：`<数据目录>/.memory5.key`

## 安全与隐私

- 不采集未配置的会话
- 黑名单 QQ 不记录
- 日记加密落盘
- 面板走 AstrBot 登录态
- 备份可校验、可解密

## 已知限制

- 归档依赖模型质量，条目需要偶尔人工修正
- 加密后无法用普通文本工具直接查看
- 大量会话时首次读取会慢一点（有缓存预热）

## 开发

- Python 3.10+
- AstrBot 4.29+
- 代码结构：`main.py`（插件主体）、`crypto.py`（加密与文件 IO）、`webui.py`（面板 API）、`pages/`（前端）
