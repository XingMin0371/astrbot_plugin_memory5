# 鱼鱼日记 · 如鱼所书（memory5）

**把聊天变成会呼吸的记忆：该记的记住，该省的省下。**

群聊越聊越长，上下文越塞越满，模型却越来越“记不住”。这个插件做的事很简单：把聊天整理成分层日记，只在需要时注入需要的那一点——**省 Token，但不丢记忆**。

> 插件内部名：`memory5`（目录、配置、数据路径始终不变）

## 一句话卖点

- **省 Token 不丢记忆**：不再把整段聊天塞进上下文，只注入相关条目，长会话也不会越聊越贵
- **缓解上下文过长**：分层 + 预算 + 去重，重要的一直在，闲聊的适时退场
- **记得住，也改得动**：面板里能按群/QQ、按日期翻，错了能改、能删、能恢复
- **隐私默认收紧**：日记落盘加密，密钥只在本机

## 为什么不是“把聊天记录全塞进去”

大多数记忆插件是“堆”：聊得越多，上下文越长，Token 越烧，模型越乱。

这个插件的思路是“整理”：

1. **先分层**：长期 / 重要 / 提醒 / 普通 / 低密度，各有保留期和注入预算
2. **再归档**：按固定时间把原始消息整理成条目，跨标签去重，重要的才进长期
3. **按需注入**：每轮只带相关的那几条，超预算自动裁剪
4. **可回看**：真正需要细节时，去面板里翻，而不是一直占着上下文

结果就是：**上下文更短，记忆更稳，花费更少。**

## 核心设计

### 分层记忆

| 层 | 内容 | 用途 |
|---|---|---|
| 长期 | 稳定的事实、关系、称呼 | 每轮优先注入 |
| 重要 | 有影响但不必长期的事实 | 按预算注入 |
| 提醒 | 带到期时间的事件 | 到点发送 + 临期注入 |
| 普通 / 低密度 | 日常闲聊 | 随机抽取，保留期短 |

分层由稳定度、影响力、信息量三个维度打分，阈值可调。

### 归档流程

```
原始消息（按天 jsonl）
  → 按时间槽触发（默认 04:05 / 16:05）
  → 批量交给模型整理成条目
  → 跨标签去重
  → 重要条目升级进长期
  → 重排序号、刷新索引
```

### 注入：省 Token 的关键

按预算拼装：长期 → 共享身份/称呼/关系 → 重要 → 随机普通；超预算按优先级裁剪。提醒只在触发点前后窗口内注入。

不是“记得越多越好”，而是“该记的刚好在”。

### 加密

三档可选：

- 高性能：AES-256-GCM
- 平衡：AES-256-GCM + HKDF-SHA256 子密钥（推荐）
- 安全：再加 HMAC-SHA256

密钥首次安装自动生成；支持轮换（半天/一天/一周/一月/一年）；密钥不可用时可三级确认重置。

### 面板

- 按范围（群/私聊）、日期（日历，可选“全部”）查看
- 长期 / 重要 / 提醒 / 普通 / 低密度 / 别名 / 回收站 / 定时任务
- 编辑、删除（回收站 7 天）、恢复、彻底删除
- 批量删除、批量调整等级（按日期 + 序号精确定位）
- 导出（JSON/Markdown）与导出历史
- 运行状态：版本、会话、加密、缓存、条目数、备份校验

### 提醒与定时任务

- 提醒：提前量、次数、补发宽限、过期回落都可调
- 重复：每天 / 每周 / 工作日
- 定时任务：一次性 / 每天 / 每周，支持图片、语音、视频

## 功能一览

- 分层日记与自动归档
- 按需注入、Token 预算可控
- 缓解长上下文：不再整段塞聊天记录
- 提醒到点发送、临期注入
- 定时任务与富媒体
- 面板查看 / 编辑 / 删除 / 恢复
- 别名管理（QQ、昵称、置信度）
- 导入导出、导出历史
- 三档加密、密钥轮换、备份校验
- 行业敏感词脱敏（内置词表 + 自定义）
- 多会话、多群、私聊

## 适合谁

- 群聊多、消息量大，Token 账单肉眼可见地涨
- 想让 AI 记住人和事，但不想把整段聊天一直塞进上下文
- 在意隐私，希望日记落盘是密文
- 需要能随时纠正记忆，而不是“模型记成什么就是什么”

## 不适合谁

- 只想无脑全文记忆、不在意 Token 的
- 不想配置模型、只想装完即用的（归档质量依赖模型）

## 安装

1. 把 `astrbot_plugin_memory5` 放到 AstrBot 数据目录的 `plugins/` 下
2. 重启 AstrBot
3. 首次启动自动生成密钥，打开插件面板即可

详细步骤见 [DEPLOY.md](DEPLOY.md)。

## 配置要点

- `记录的会话`：填 `group:群号` 或 `private:QQ号`，不填不归档
- `管理员 QQ`：可查看全部日记、使用重要级命令
- `机器人 QQ`：识别自身消息
- 注入预算：按需调，默认 3600 字符
- 加密强度：平衡即可；切换会自动重加密

## 命令

```
/记忆查看 [日期] [QQ] [普通级|提醒级|重要级|低密度级] [条数]
```

长期记忆只在面板查看。

## 数据目录

```
<数据目录>/memory5/
├─ group_xxx/ private_xxx/
│  ├─ core.md important.jsonl remind.jsonl
│  ├─ daily/*.jsonl raw/*.jsonl
│  ├─ aliases.json index.json
├─ tasks.json
├─ trash/ media/ backup_policy.json
└─ export_history.json
```

密钥：`<数据目录>/.memory5.key`

## 安全与隐私

- 不采集未配置的会话
- 黑名单 QQ 不记录
- 日记加密落盘
- 面板走 AstrBot 登录态
- 备份可校验、可解密

## 已知限制

- 归档依赖模型质量，条目需要偶尔人工修正
- 加密后无法用普通文本工具直接查看
- 大量会话首次读取会慢一点（有缓存预热）

## 开发

- Python 3.10+
- AstrBot 4.29+
- 结构：`main.py`（主体）、`crypto.py`（加密与 IO）、`webui.py`（面板 API）、`pages/`（前端）
